# Generated results

Research workflows write generated artifacts here:

- `exploratory/` for exploratory figures and summaries;
- `reverse_label/` for inverse spectrum-to-parameter diagnostics;
- `modelling/` for fitted-model artifacts, metrics, and comparisons;
- `log_modelling/` for log10-space fitted-model artifacts, metrics, and comparisons;
- `validation/` for predictive-performance studies.

Generated artifacts are ignored by Git by default because the canonical source
is the versioned code, environment, and input data. Commit a selected result
only when it is needed as a stable paper artifact, and document which workflow
created it.

Human-readable CV reports are generated by `make modelling_sklearn` under
`modelling/02_augmented_wavelength/cv/` for linear Model 2 outputs and
`log_modelling/02_augmented_wavelength/cv/` for log10 Model 2 outputs. The Model
1A vs 1B MF-GP contrast is generated under
`(log_)modelling/01_per_wavelength_ar1/comparison/` on each scale.

For the paper-facing model-comparison split, use:

- `modelling/02_augmented_wavelength/cv/` for sklearn/mf_gp custom-kernel
  linear-scale comparisons, with log10 outputs in
  `log_modelling/02_augmented_wavelength/cv/`.
- `modelling/03_gpboost_comparison/matched_subsample/` for GPBoost comparisons
  on the same canonical subsample as the sklearn comparison.
- `modelling/03_gpboost_comparison/max_data/` for GPBoost comparisons using the
  larger configurable max-data settings.
