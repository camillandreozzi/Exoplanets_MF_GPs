# Generated results

Research workflows write generated artifacts here:

- `exploratory/` for exploratory figures and summaries;
- `reverse_label/` for inverse spectrum-to-parameter diagnostics;
- `modelling/` for fitted-model artifacts, metrics, and comparisons;
- `validation/` for predictive-performance studies.

Generated artifacts are ignored by Git by default because the canonical source
is the versioned code, environment, and input data. Commit a selected result
only when it is needed as a stable paper artifact, and document which workflow
created it.

Human-readable CV reports are generated by
`make rho-loo-validation` under
`validation/03_rho_loo_model_comparison/`, including the combined
`CV_COMPARISON_REPORT.md` and per-comparison `CV_REPORT.md` files for
non-log Model 1A vs 1B, log10 Model 1A vs 1B, and log10 vs non-log.
